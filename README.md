# Map

CAD of the **Eurobot 2026 game table/map** and its elements.

## Contents
- `map*.STL` / `map - hazel nut crate colored-*.STL` — the map and the colored hazelnut crates
- `Part*^balise 2.0*.STL` — parts of the beacon (balise 2.0) placed on the map
- `granary (2).png`, `table png` — reference images

---

Part of the CAD work of the **Aerobotix (INSAT, Tunisia) Eurobot 2026 team** — see the [organization](https://github.com/Eurobot-2026-CAD-departement) for the other repositories.
